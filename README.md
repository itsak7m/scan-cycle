# Scan Cycle

A browser game that teaches real PLC ladder logic on a pharmaceutical bottle-filling line.
You write the ladder logic. The game runs the line and tests your program like a FAT.

**Status:** Phase 0 — repository set up. Game coming soon.

**Play it:** https://itsak7m.github.io/scan-cycle/ *(live after GitHub Pages is enabled)*

## ملخص بالعربي

لعبة بالمتصفح بتعلّمك ladder logic حقيقي لخط تعبئة أدوية. إنت بتكتب المنطق، واللعبة بتشغّل الخط وبتفحص برنامجك بسيناريوهات اختبار زي الـ FAT.
